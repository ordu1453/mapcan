# Your own map

**Create Map** asks for a template and a title, and saves the map where you choose.

| Template | Starts with |
|---|---|
| CANopen | A bus and a device with its PDOs |
| SAE J1939 | An ECU with one PGN |
| CAN with explicit IDs | A bus and a device |
| Empty | A bus |

Then add devices, frames and signals with **+** in the Map view, or type the YAML: completion, hovers and
checks work as you type.
