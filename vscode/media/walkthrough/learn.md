# mapcan

A YAML map of CAN signals as the single source of truth: one file for the documentation, the DBC and the code.

- [Repository](https://github.com/ordu1453/mapcan): the format, examples, the command line and the web editor
- [PyPI](https://pypi.org/project/mapcan/): `mapcan` for CI and other tools
- [Issues](https://github.com/ordu1453/mapcan/issues): questions, bugs and ideas
